# Giga Grains 0.2.0 (M2, Giga)

M2 turns M1's single-layer cloud into the full instrument and effect: four layers, minutes-long
buffers, an HQ interpolation tier, Smear and a Spectral source, a filter, delay and limiter, 48
factory presets, and the Edit, Mod and FX views. **This is an unpublished draft release**, the
director's own installers for host testing: nothing is public, and there are no betas, before M5
(`0.5.0-beta.1` is the first public release).

## What changed

M2 was built as seven sub-projects.

- **Layers and structure.** Four layers, A to D, each with its own Source (Sample, Live or
  Resample, and Spectral), on/off, level and per-layer controls, blended by an XY pad (the
  morph). A 48-slot mod matrix routes LFOs, envelopes, random, step, the follower, MIDI sources
  (mod wheel, aftertouch, pitch bend, velocity, key) and the transport to any target; per-grain
  pitch and size spreads. The patch is at version 2, and a version-1 patch (M1) migrates on load.
- **Sources and persistence.** Rings of 1 to 300 s with loop, loop length, overdub, splices and
  capture (a ring's span becomes a layer's sample or a float32 WAV); a Resample source that
  hears the plugin's own output, with Feedback; a memory cap and a sample pool; sessions save
  the rings that are held, and the four loaders and the Ring Length resize keep them.
- **Engine scale and quality.** An HQ sinc tier (Eco, Normal, HQ per layer), file mipmaps, a
  deterministic CPU budget (Budget, 256 to 16,384 Normal grains' worth, with quotas and an
  overload ladder that lowers the tier, then drops new grains, then steals with fades; it never
  clicks or drops out), a pool of 16,384 grains, and AVX2 kernels chosen when the plugin loads.
- **Extremes and the FX chain.** Smear, the Spectral kind, two filtered grain buses per layer
  (Bus Split, a filter each), a global delay (with ping-pong) and a limiter (Off, Soft, Peak).
  Together with sub-project 2's, 283 parameters in all and thirteen remote-controls pages.
- **Presets and content.** The `.ggpreset` file, INIT, CLAP preset discovery, a preset browser,
  Mutate, and 48 factory presets (24 for each product; eight of the FX's are MIDI-driven) over 51
  CC0 sample files (VSCO 2: CE strings and brass beside VCSL), carried by the installers'
  Content component.
- **Views.** The Perform, Edit, Mod and FX views, four canvas lanes with a pitch axis, the layer
  strip, undo and redo, a dark and a light theme, and the About box; 960 x 600 down to 640 x 360.
- **The close.** A consistency pass over the design documents, a from-scratch build setup, the
  listening gate and the host checks (Live 12 with the VST3 and the AU, Bitwig with the CLAP and
  the VST3, both products in each: all passed), and the benchmark figures below.

**Figures** (the director's Apple M5 Max, idle, `docs/benchmarks/2026-11-03-m2-*.json`): the
headline X, 2,000 grains of 100 ms through the engine, is **19.4%** of one core at block 256
(23.3% at 32, 21.0% at 64), re-measured against M1's published 19.5%; the canvas draws 8,192
grains in **2.85 ms** a frame (the budget is 3 ms). HQ costs 6.9 to 7.9 times Normal.

**Changed in the toolchain.** dr_libs moved to `35b5c39`, fmt to 12.2.0 and clap-wrapper to
`next` at `4585bc6`; the sanitizer jobs use LLVM 23.1.4 and the Windows installer is built with
Inno Setup 7.1.1. No sound changes with them: all 108 golden renders keep their audio. **The
Linux build now needs Ubuntu 24.04's glibc (2.39) or newer** and no longer runs on Ubuntu 22.04.

## Known issues

- **A grain stream stops at note-off** in the instrument, so an envelope's release is heard only
  in the last grains and the reverb's tail. The director wants it to continue; M3's Voice
  scheduler will build that (carry-over row 404).
- **AU hosts never see the plugins' tail**, and in the AU the preset name is not retained across a
  state save; a value set on an idle AU with no editor open may be missed by a save that follows
  at once (rows 218, 87, 88; clap-wrapper's AUv2). The CLAP and VST3 are not affected.
- **Two notes on one key share one held state,** so the first note-off releases both (row 184;
  M3).
- **Two rare test failures are being watched:** the ring reader's copy check (row 403) and a block
  size check under Rosetta (row 234) each failed once or twice in CI and never reproduced. Neither
  has been heard in use.
- HQ's CPU weights are provisional until M5's calibration (row 307).

The open carry-over is 15 rows (`docs/m2-carry-over.md`); the rest are upstream-blocked or wait
for M3, M5 or 1.0.0.

## The installers

- macOS (11 or later, Apple silicon and Intel): `giga-grains-0.2.0-macos.dmg`, signed and
  notarized. Open it and run the installer it holds.
- Windows (x64): `giga-grains-0.2.0-windows-x64.exe`, an installer, or
  `giga-grains-0.2.0-windows-x64.zip` to copy the files by hand. Both are unsigned, so
  SmartScreen warns about an unknown publisher once.
- Linux (x86_64): `giga-grains-0.2.0-linux-x86_64.tar.gz`; its README says where each file
  goes. It needs glibc 2.39 or newer (Ubuntu 24.04 or later).

`SHA256SUMS.txt` holds every file's checksum.

Giga Grains is free software, licensed under the GNU Affero General Public License, version 3 or

https://github.com/sethbc/giga-grains:

```sh
git clone --recurse-submodules --branch v0.2.0 https://github.com/sethbc/giga-grains
```

or the source tarball attached to this release, `giga-grains-0.2.0-source.tar.gz`, which
holds the tagged tree with every submodule at its pinned commit. The build also uses the VST3
SDK, Apple's AudioUnitSDK, RtAudio, RtMidi and wil, which it downloads: the tags it fetches are
named in `libs/clap/clap-wrapper/cmake/base_sdks.cmake`, and `scripts/fetch-sdks.sh` fetches
those same tags. The README in the source says how to build.
