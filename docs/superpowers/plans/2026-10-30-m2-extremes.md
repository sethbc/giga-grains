# M2 Extremes and the FX Chain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every layer a Smear control and a Spectral Smear source kind, two grain buses with a
filter each, and the instance a global delay and limiter, with every new stage the exact identity
at rest so all 36 existing goldens keep their WAV SHA-256s.

**Architecture:**
- **Smear** is four couplings in `toCloudParams` and the scheduler's draws: a raised effective
  density, a Size-scaled position jitter, a micro-detune and the latched gain following the raised
  overlap. At 0 nothing is drawn and nothing changes.
- **The Spectral Smear source** (`gg::SpectralSource`, `engine/include/gg/spectral/`) is a
  paulstretch-style STFT on pffft writing one sample per output sample into a `LiveSource` of its
  own; a Spectral grain is a ring grain on slot 3, so the live kernels serve it at every tier.
- **Buses:** each grain's row carries a bus bit latched at spawn; `Engine::process` takes a second
  output pair; the layer's task filters each bus (`CytomicSVF`, coefficients per grid cell,
  interpolated per sample, type changes crossfaded) and sums them, bus 2 only once a grain has been
  on it (a sticky flag).
- **The serial tail** gains an in-house `Delay` (exact bypass, tape-like time glide, soft-clipped
  loop) before the reverb's return and a `Limiter` (Off: M1's expression and association; Soft:
  M1's law at a ceiling; Peak: zero-lookahead) before the mix.
- **Forty parameters** in the `0x..60`–`0x..67` blocks; no patch bump; five remote pages.

**Tech Stack:** C++23, CMake 3.22/Ninja, Catch2, pffft (already built as `gg::pffft`), sst-filters'
`CytomicSVF` (header-only, `PRIVATE` to `gg-core`), sst-basic-blocks `ParamMetaData`, `gg-render`,
`gg-bench`.

**Spec:** `docs/superpowers/specs/2026-10-30-m2-extremes-design.md` (approved by the programme
manager 2026-10-30; the director's D1–D8, every recommended option). Read it before your task;
its sections are cited as "spec §n". The programme design
(`docs/superpowers/specs/2026-10-29-m2-programme-design.md` §6.4, §7) is the charter behind it,
and the layers spec (`2026-10-29-m2-layers-design.md`) describes what you build on.

## Global Constraints

**Non-negotiables** (CLAUDE.md; spec §4, §7):
- **Audio thread and pool threads:** no allocation, locks, I/O, syscalls, host calls or unbounded
  loops; RTSan-clean; 0- and 1-sample blocks; `params.flush` trivial. The spectral ring, the STFT's
  buffers and pffft setup (its work buffer included), the delay line and the filters are allocated
  with the `Engine` or the `Processor`.
- **Determinism:** output bit-identical at any host block size and with no thread pool or a pool of
  1, 2 or 8 workers. Every new draw is counter-keyed: `rng::Field` gains `SmearJitter`,
  `SmearDetune`, `Bus` and `SpectralPhase`, numbered 9, 10, 11, 12 on this branch and **renumbered
  at the rebase onto sub-projects 3 and 2** (Task 18), after which this sub-project's goldens are
  re-rendered. No libm in the audio path: `exp2Det`, `logDet`, `sineDet`, `std::sqrt` and plain
  arithmetic only (CytomicSVF's `fasttan` is plain arithmetic; pffft is plain arithmetic). Layers
  summed in order A to D; each bus in spawn order; the two buses in a fixed order.
- **The M1 and wave-1 sound is unchanged:** with Smear 0, Bus Split 0, both filters Off, no
  Spectral layer, Delay Amount 0 and Limiter Mode Off, every one of the 36 goldens keeps its WAV
  SHA-256, the sign of zero included (`scripts/update-goldens.sh` before and after every DSP task;
  the hash list in the commit). No `.events.jsonl` changes until the rebase renumbers the fields.
- **Stability contracts:** IDs append-only; no new scope; only indices `0x60`–`0x67` of scope 0 and
  of each layer scope are taken; no patch version bump; no new state chunk.

**Smear's law** (spec §6.1, D8 option 1), with s Smear, D Density in Hz, S Size in seconds:
`T = 8 + 24s`; `D_eff = D + s × (min(400, max(D, T / S)) − D)`; `smearJitterSec = 0.5 × s × S`;
`smearDetuneSemitones = 0.5 × s`; `gain = 1 / sqrt(max(1, D_eff × S))`. At s = 0: `D_eff = D`, both
amplitudes 0, no draw.

**The chain** (spec §6.6): per layer, inside its task, `b1, b2 = Σ grains by bus` (each spawn
order), `w = F1(b1) ⊕ F2(b2)` (bus 2 added only once a grain has been on it; `F` the identity when
Off), then the diffuser, Level, `softLimit`, the morph weight, as wave 1. After the join:
`wet' = wet [+ Amount × delayRead]` (added only where Amount's ramp ≠ 0); `rIn` from `wet'`; limiter
Off: `out = (d·(1 − m) + wet'·m) [+ softLimit(a·r)]` (FX) / `out = wet' [+ softLimit(a·r)]`
(instrument), today's expressions and association; Soft or Peak: the bracketed wet side is formed
first, limited, and added to `d·(1 − m)`.
