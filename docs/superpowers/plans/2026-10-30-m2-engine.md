# M2 Engine Scale and Quality Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the engine a deterministic CPU budget with the overload ladder (lower the tier, drop,
steal with fades), the HQ windowed-sinc tier behind a per-layer Quality parameter, the file mip
pyramid with a level per grain, the pool to 16,384, the sweep harness in CI, three report-only
`gg-bench` cases and the measured AVX2 spike, while every one of the 36 goldens keeps its WAV
SHA-256.

**Architecture:**
- **The pool's admission heap becomes a weighted ledger with handles** (`GrainPool`): each entry
  is a grain's end, weight and row; a steal decreases one key. The `Engine` runs the ladder per
  draw against a quota the `Processor` sets serially at grid boundaries from the Budget parameter
  and the rendering layers, so the four layer tasks never share state.
- **A third reader policy, `Sinc`**, joins `Hermite` and `Linear` in `GrainKernels.h`: one
  continuous windowed-sinc table (`SincTable`), stretched by the grain's residual rate, with the
  scalar reference defining the bits and the SIMD kernels matching them by `memcmp`.
- **`PreparedSource` holds the pyramid**: level 0 as today, levels 1 to 4 one copy each, built
  offline by a half-band decimator (`Mipmap.h`). The engine latches a level per HQ grain from its
  rate; the kernels read whichever level the source has, positions scaled by an exact power of two.
- **Parameters** Quality (×4, index `0x50`) and Budget (`0x000050`) append in the reserved block; no
  patch bump. The grain-event line gains `"tier"` and `"lvl"`, and steals get their own line.
- **The sweep harness** is a `[sweep]` Catch2 family in `gg-tests`; **AVX2** is a second kernel TU
  chosen at load, measured in-process against a forced-SSE case.

**Tech Stack:** C++23, CMake 3.22/Ninja, Catch2, sst-basic-blocks SIMD (`SIMD_M128`) and
`ParamMetaData`, `<immintrin.h>` (the AVX2 TU, x86-64 only), nlohmann/json and fmt (gg-render),
`gg-bench`.

**Spec:** `docs/superpowers/specs/2026-10-30-m2-engine-design.md` (approved by the programme
manager 2026-10-30; the director's D1–D5 recorded, every recommended option). Read it before your
task; its sections are cited as "spec §n". The programme design
(`docs/superpowers/specs/2026-10-29-m2-programme-design.md` §6.3, §7) is the charter behind it.

## Global Constraints

**Non-negotiables** (CLAUDE.md; spec §4, §7):
- **Audio thread and pool threads:** no allocation, locks, I/O, syscalls or unbounded loops;
  RTSan-clean; 0- and 1-sample blocks; `params.flush` trivial. Tables and pyramids are built in
  constructors or `PreparedSource::make`, never in `process()`.
- **Determinism:** output bit-identical at block sizes 1, 32, 64, 511 and 4096 and with no thread
  pool or a stub pool of 1, 2 or 8 workers. Every ladder decision is a function of the onset, the
  grains' latched ends and weights, the quota in effect at the last grid boundary and the weight
  table: no clock, load, thread or call boundary. Weights are integers. Plain IEEE arithmetic in
  the kernels, `-ffp-contract=off` everywhere (the AVX2 TU included), no libm on the audio thread
  (the tables use `std::sin`/`std::cos` at construction, as `HannTable` does). No `std::`
  distribution. No new `rng::Field`.
- **The M1 sound is unchanged:** with every layer at Normal and no quota binding, every one of
  the 36 goldens keeps its WAV SHA-256 through every task (`scripts/update-goldens.sh` before and
  after every DSP task; the hash list in the commit). Only Task 9 rewrites the `.events.jsonl`
  files, by insertion of `"tier"` and `"lvl"`; no `.metrics.json` or WAV moves.
- **Stability contracts:** IDs append-only; no new scope; only index `0x50` of each scope is used
  (`0x51`–`0x5F` stay free, `0x40`–`0x4F` and `0x60`–`0x7F` are the other sub-projects'); no patch
  version bump; no new state chunk.
- **Ownership** (spec §4): `engine/include/gg/grain/`, `engine/src/{GrainPool,Engine}.cpp`,
  `Interpolate.h`, `PreparedSource.{h,cpp}`, the new `Mipmap.{h,cpp}` and `SincTable.h`,
  `tools/gg-bench`, `tests/sweep/`. `LiveSource.{h,cpp}` **only** the two additions Task 1 names
  (`gatherTaps<16>` and `kGuardFrames` = 15); `Processor.{h,cpp}`, `ParamIds.{h,cpp}`,
  `ParamMap.{h,cpp}`, `tests/CMakeLists.txt`, INTENT by addition only. No edit under `libs/`.
- **Carry-over policy:** row 51 of `docs/m2-carry-over.md` closes here (Task 2, marked in Task
  13); no net growth (11 open rows at the start; 10 at the end).
- **Formatting and commits:** `scripts/format.sh` before every commit; test case names ASCII only;
  every new test file goes in `tests/CMakeLists.txt`'s `gg-tests` source list; commits end with
  `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Run `scripts/check.sh` before
  reporting a task done and paste its summary.

## Review Focus

The spec implies these inputs but no task's tests exercised them until this list was written;
each has a test pinned to the owning task:
1. **Budget automated below a layer's current load mid-cloud:** nothing already sounding is cut
   at the boundary; only admissions from there on see the smaller quota, and the first new grains
   steal one old grain each. Pinned in Task 7 ("lowering Budget under a cloud cuts nothing at
   once").
2. **A source swap to a source with fewer levels while HQ grains read level 3:** each grain reads
   the new source's top level, scaled by its decimation, with no read outside it. Pinned in Task 5
   ("a swap to a source with fewer levels reads its top level").
3. **Quality modulated per cell by a fast LFO under overload:** no allocation, finite output,
   every grain's tier latched at its onset and reported. Pinned in Task 7 ("quality modulated per
   cell under overload does not allocate").
4. **Stealing a grain shorter than the fade** (Size 5 ms, 240 samples): the fade covers what
   remains, its factor starts at 1 and never goes negative, no click. Pinned in Task 6 ("stealing
   a short grain fades over what remains").
5. **An HQ live grain near the seam while the ring freezes:** the sinc's fade reaches 0 before any
   of its 16 taps leaves the window, so no stale slot is read. Pinned in Task 1 ("simd live kernel
   matches the reference through freeze and wrap" with `Sinc`, plus "hq live reads nothing beyond
   the window").

**Interfaces:**
- Produces:
  - `enum class Tier : uint8_t { Eco, Normal, HQ };` with `HQ`'s doc "The 16-tap windowed sinc
    (SincTable) over taps floor(pos) − 7 .. floor(pos) + 8, stretched by the residual rate".
  - `class gg::SincTable` (`SincTable.h`): constants per Global Constraints; `SincTable()` fills
    `std::array<float, kPoints> table_` with `h(x) = sinc(x) × kaiser(x / 8, kBeta)` at
    `x = −8 + j / 512`, computed in double (`std::sin`, a series for the Bessel I₀ to 1e-12), as
    floats; `float at(float x) const noexcept`: 0 unless `x >= −8 && x <= 8`; else
    `u = (x + 8.0f) × 512.0f`, `j = min(uint32(u), kPoints − 2)`, `t = u − float(j)`,
    `table_[j] + (table_[j + 1] − table_[j]) × t` (exactly this float order); `const float
    *points() const`.
  - `struct kernels::ReadParams { const SincTable *sinc; float stretch; }` passed as the last
    argument of every reader's `read`, `read4`, `read4Pair` and `readLive`; `Hermite` and
    `Linear` ignore it. `float kernels::stretchOf(double residualRate) noexcept` =
    `residualRate > 1.0 ? float(1.0 / residualRate) : 1.0f` (one IEEE division). In this task
    the residual rate is `rows.rate[i]` (level 0); Task 5 scales it.
  - `struct kernels::Tables { const HannTable &hann; const SincTable &sinc; }` replaces the
    `const HannTable &hann` parameter of `renderSampleRef`, `renderSampleSimd`, `renderLiveRef`,
    `renderLiveSimd`, `renderInterior` and `renderInteriorSteps` (callers: `Engine::renderPool`,
    the tests, `gg-bench`'s `Kernels.h` is untouched since it holds its own copies).
  - `struct kernels::Sinc` with `kBefore = 7`, `kAfter = 8`, and:
    - `static float read(const float *data, int64_t frames, double pos, const ReadParams &p)`:
      0 unless `pos > −9.0 && pos < double(frames) + 8.0`; `base = floor(pos)`, `i = int64(base)`,
      `frac = float(pos − base)`; then for `k = −7 … 8` in order: `x = (float(k) − frac) ×
      p.stretch`, `c = p.sinc->at(x)`, `num += c × tap(data, frames, i + k)`, `den += c` (all
      `float`); returns `den != 0.0f ? num / den : 0.0f`. A stride template `template <int64_t
      kStride = 1>` as the others have (Task 3's planar levels use 1, pairs 2).
    - `read4` / `read4Pair`: the same arithmetic in 4 lanes, lane-wise in the same order
      (`c` as a 4-lane vector from four scalar `at` lookups per tap, `num` and `den` 4-lane
      accumulators, one `div_ps` at the end). The gather layout is the builder's.
    - `static bool readLive(const LiveSource &live, double pos, int64_t head, LiveSource::Cursor
      &cursor, const ReadParams &p, float &l, float &r)`: `live.gatherTaps<16>(pos, head, cursor,
      taps16L, taps16R)` then the same sums over the gathered taps.
    - `static double fade(const LiveSource &live, double pos, int64_t head)`: the spec's HQ fade,
      `unit((R − 1 − (pos + 8)) / M) × unit(((pos − 7) − (R − N)) / M)`; `Hermite::fade` and
      `Linear::fade` return `live.fade(pos, head)`. `renderLiveRef` and `liveRun` call
      `Reader::fade`, and `liveRun`'s margin conditions use `Reader::kBefore` / `kAfter` in place
      of the literal 1 and 2 (for Hermite that is the same expression, bit for bit).
  - `template <int kTaps> bool LiveSource::gatherTaps(double pos, int64_t head, Cursor &cursor,
    float *left, float *right) const noexcept` (kTaps 2, 4 or 16; `kBefore` = 0, 1, 7): the
    window check and the slot fetch `readTaps` does today, writing the raw taps; `readTaps` is
    rewritten to call it and apply its curve, bit for bit as before. `kGuardFrames` = 15 (the
    mirror in `write()` and the storage size follow it; no output changes).
  - `Engine::renderPool` dispatches `Tier::HQ` to `renderSampleSimd<Sinc>` / `renderLiveSimd<Sinc>`
    with `Tables{hann_, sinc_}`.
