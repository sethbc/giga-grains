# M3 Microtuning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each key's pitch comes from the tuning in effect, in both modes and both products. The order is MTS-ESP when a master is connected and the switch is On, else a loaded Scala `.scl`/`.kbm` (saved with the session in a `TUNE` chunk), else 12-TET. At rest every render is bit-identical.

**Architecture:** `gg-core` turns Scala texts into a `TuningTable` (128 key terms in semitones above 12-TET's C4, plus unmapped bits). tuning-library parses and validates the texts. Our own port of its mapping turns them into the table with deterministic math. The `Processor` holds a local table and an MTS snapshot. At each call's start it resolves the effective table into one array that every layer's Cloud scheduler reads through a pointer. The voice pass reads the same array. A note-on for an unmapped key is dropped at intake and gets its `NOTE_END`. The plugin compiles ODDSound's 0BSD client. A process-wide poller thread reads each instance's master off the audio thread and hands snapshots over through `LatestValue`.

**Tech Stack:** C++23, tuning-library (header-only, MIT), the MTS-ESP client (0BSD, loads libMTS at run time), CLAP, Catch2, `gg-render` goldens, JUCE (the minimal UI).

**Spec:** `docs/superpowers/specs/2026-11-07-m3-tuning-design.md` (parent: `docs/superpowers/specs/2026-11-07-m3-program-design.md`). File references are at `89d9d0e`, this branch after merging `m3-voice` (sub-project 1 through its Task 7 and Task 9).

## Adjustments to the spec (plan-level calls, made without the director; each noted in the final report)

- **A1 (fits the merged code).** T7's `NOTE_END` for an unmapped key uses sub-project 1's ended-note queue. The intake pushes `EndedNote{noteId, channel, key}` into `ended_` through the existing `Processor::pushEnded` path (`core/src/Processor.cpp:1153`), so `takeEndedNotes` delivers it. The plugin emits it with the port it uses for every ended note. The note never enters `NoteTable`, so it advances no `noteOrdinal_` and doesn't move Velocity or Key.
- **A2.** Note Pitch is computed as `((60.0 + s(k)) + bend) + tuning`, not as `60 + notePitch()`. The first is bit-identical to today's `(key + bend) + tuning` in 12-TET, because `60.0 + (k − 60.0)` is exactly k. The second isn't always. `notePitch()` = `(s(k) + bend) + tuning` serves `pitchIn` and sub-project 3.
- **A3.** At the pin, `withSkippedNotesInterpolated` interpolates over tuning-library's 512-key table (keys −256 to 255). At either end it uses the nearest mapped neighbour's value, not that value "plus one semitone a key" as spec §5.2 step 4 says. The port follows the pin, as T4 requires.
- **A4.** The FX has no note gate. During an unmapped key's span in `fx-tuning-unmapped`, the FX's cloud therefore keeps playing at its own Pitch, with no key term and no freeze, rather than "no new grains". A 5-degree scale can't fill 7 white keys, so the `.kbm` maps C, D, E, G and A and leaves F, B and the black keys `x`.
- **A5.** `scripts/release/source-tarball.sh` leaves out `libs/MTS-ESP/libMTS/` (ODDSound's closed binaries and their installers), so no release artifact carries libMTS (T10).
- **A6.** The poller calls the client through a function table (`MtsApi`), so the tests can drive it with a fake master. Production uses the real client's functions.
- **A7.** The real-master test skips when `MTS_CanRegisterMaster()` is false (another master, such as the director's DAW, holds MTS-ESP). With `GG_REQUIRE_MTS_ESP=1` it fails instead.
- **A8.** `Processor` becomes explicitly non-copyable and non-movable, because its engines hold its table's address.
- **A9.** A preset whose only tuning is a newer-version `TUNE` keeps the instance's tuning. `encodeState` writes `tuning` when it holds one, else `newerTuning`; never both.
- **A10.** In `gg-render`, a `state`'s or `preset`'s `TUNE` that `tuningFromScala` refuses gives a warning on stderr (`gg-render: warning: the state's tuning didn't load: <message>`) and a 12-TET render with exit 0. The spec's own `tuning` key, refused, is exit 2.
- **A11.** The Tuning… menu's first disabled line always names what is in effect. When there is a last load failure, a second disabled line shows it.
- **A12.** `GG_NO_MTS_ESP` is set by `PluginHarness.h`, `gg-snap` and `gg-au-state-tests` (the last also makes whole instances).
- **A13.** The fake-master tests carry `[plugin][tuning]`, never `[mts]`, so `ctest -L mts` selects only the real-master executable.

## Review Focus

1. **A `.scl` saved on Windows or in Latin-1: CRLF line ends, a UTF-8 BOM, a description in Latin-1, a tab before a cents value.** It loads, and its cents re-parse gives the same values as the LF version. (Task 2's `tuning cents parse ignores CR, BOM and tabs`.)
2. **Instances created and destroyed rapidly while the poller runs** (a host's scan, or a project closing 40 instances). Nothing deadlocks, no client is used after deregistration, and the thread is joined when the last instance goes. (Task 10's `mts poller survives register and deregister churn`.)
3. **A master sending NaN, 0, a negative frequency or 1e300 for some keys.** Those keys keep their 12-TET term; the others follow the master; every entry stays finite and within ±1024. (Task 5's `tuning from frequencies keeps twelve tet for bad frequencies`.)
4. **A CLAP note expression, a note-off by ID or a poly pressure for the ID of a note dropped as unmapped.** Each is ignored without touching another note; another held note with the same key keeps sounding. (Task 5's `an unmapped note's id reaches no other note`.)
5. **A hostile `.kbm`: a reference frequency of 0, a negative one, `1e30`, `inf` or 20 kHz on key 0.** 0, negative, non-finite and over-long values are refused with a message. Extreme finite values give a finite table, clamped to ±1024, so grains clamp at ±48 and nothing is NaN. (Task 2's `tuning refuses a nonpositive or nonfinite reference` and `tuning clamps an extreme reference`.)
