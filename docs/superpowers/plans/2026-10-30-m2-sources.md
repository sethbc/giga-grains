# M2 Sources and Persistence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every layer a ring of any length with loop, overdub, splices and capture, a Resample
source on the instance's output, a per-instance memory cap with a process-wide sample pool, and a
session that saves and restores held rings and captures bit-exactly, while every M1 and
sub-project-1 golden keeps its WAV SHA-256.

**Architecture:**
- **The ring's frames move into a `RingStorage`** the main thread allocates and `LiveSource`
  adopts, so a resize or a restore never allocates on the audio thread; the window the grains read
  becomes a length `W` (the ring, a loop or a splice), and overdub is one more term of the write.
  Nothing new reaches the kernels: Resample is a Live-mode engine whose ring is fed by a 256-late
  tap in the `Processor`.
- **Persistence is three additive chunks' worth of data on the version-1 container:** `MEDI`
  version 2 (four samples and four rings with layers), `AUDI` (float32 WAV payloads by id) and
  `INST` (the memory cap). `gg-media` encodes a ring to WAV bytes and decodes them back, from a file
  or from memory, so an embedded and a filed capture are the same bytes.
- **The plugin grows a `MediaSession`** per instance: four `SampleLoader`s, the memory budget,
  the ring save and restore, the resize watcher, capture and collect. `gg-render` gets `state`,
  `--save-state` and `operations`, cutting its calls at an operation's frame.
- **The ring pyramids come last,** after the rebase onto the merged sub-project 3, behind its
  accessor and with its filter taps.

**Tech Stack:** C++23, CMake 3.22/Ninja, Catch2, dr_wav (memory reader), r8brain, tinyxml through
PatchBase, nlohmann/json (gg-render), CLI11, `gg-bench`. No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-30-m2-sources-design.md` (approved by the programme
manager 2026-10-30; the director's D1–D7 recorded, every recommended option). Read it before your
task; its sections are cited as "spec §n". The programme design
(`docs/superpowers/specs/2026-10-29-m2-programme-design.md` §6.2, §7) is the charter behind it.

## Global Constraints

**Non-negotiables** (CLAUDE.md; spec §4, §7):
- **Audio thread:** no allocation, locks, I/O, syscalls, host calls or unbounded loops;
  RTSan-clean; 0- and 1-sample blocks; `params.flush` trivial. The one copy the audio thread makes
  for a ring adoption is at most `kAdoptCopyFrames` = 8,192 frames per channel (and their level
  frames, Task 12). Everything else (allocation, files, hashing, the captures folder, the pool, the
  budget's check, the capture read) is main or loader thread.
- **Determinism:** output bit-identical at any host block size and `maxBlockSize` and with any
  thread pool; the operations use no RNG; Loop, Loop Length, Overdub, Splice, the commands and the
  tap apply on the control grid or by absolute time; a resize and a restore land at a call's start
  (as a sample swap does) and `gg-render` makes them before the first call. Plain IEEE arithmetic
  only; `-ffp-contract=off` already set.
- **The sound at rest is unchanged:** with Ring Length 16 s, Loop off, Overdub 0, Splice 0, no
  Resample layer, nothing embedded and the cap at its default, every one of the 36 goldens keeps
  its WAV SHA-256 (`scripts/update-goldens.sh` before and after every DSP task; the hash list in
  the commit), the sign of zero included. The only expected move is sub-project 3's
  `fx-hq-live-level0`, regenerated as `fx-hq-live` in Task 12.
- **Stability contracts:** IDs append-only; the five new indices are `0x40`–`0x44` in scopes 1 to
  4 alone; scope 0 takes nothing; no new scope; no patch version bump (`kPatchVersion` stays 2);
  the container version stays 1; chunks `AUDI` and `INST` are this sub-project's, nobody else's.
- **Ownership** (programme design §6.2; spec §4): `engine/include/gg/source/` and `engine/src/
  LiveSource.cpp`, `media/`, `SessionState.h`, `SourceExchange.h`, `plugin/src/SampleLoader*`,
  `SearchCache*`, the `Processor`'s source adoption and tap. Shared files (`Processor.h`/`.cpp`,
  `Engine.h`/`.cpp`, `ParamIds.h`, `ParamMap.h`, `tests/CMakeLists.txt`, INTENT) by addition.
  Nothing in `ui/`, `engine/include/gg/grain/`, `core/src/space/` or `libs/`. Sub-project 5 adds
  `gg/media/ContentPaths.h` under `media/` as a new file only: don't create a file of that name.
- **Carry-over policy:** 11 open rows at the start and 11 at the end; none closes here; none is
  added. Every reviewer minor is fixed in the fix wave.
- **Formatting and commits:** `scripts/format.sh` before every commit; test case names ASCII
  only; commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Run
  `scripts/check.sh` before reporting a task done and paste its summary.

## Review Focus

The spec implies these inputs but no task's tests exercised them until this list was written;
each has a test pinned to the owning task:
1. **Loop Length longer than the ring, or Splice selected with no marks:** the window is the whole
   ring, nothing is dropped, and the output equals the unlooped render bit for bit. Pinned in
   Task 1 ("a loop longer than the ring is the ring").
2. **Ring Length changed while the plugin is inactive, or in a state loaded before `activate()`:**
   no exchange runs; the next `activate()` builds the ring at the new length and the first call
   renders with it. Pinned in Task 7 ("a ring length set while inactive applies at activation").
3. **A ring saved at 44.1 kHz restored in a 48 kHz host:** converted on the main thread, the frame
   count `llround(frames × 48000 / 44100)`, the marks scaled the same way, the restore holds it.
   Pinned in Task 6 ("a ring saved at another rate restores converted").
4. **A filed ring whose captures folder isn't on this machine:** the state loads, the layer's
   status is Missing, no ring is restored and its Freeze stays live until toggled (FR-8). Pinned in
   Task 7 ("a filed ring that can't be found loads the rest and stays live").
5. **An `AUDI` payload referenced by no entry, or an entry referencing a missing id:** the first is
   ignored (an older build's leftovers), the second fails the state (a malformed entry, R9's
   mirror). Pinned in Task 3 ("an entry naming a missing payload fails the state").

```cpp
// RingStorage.h: the frames of one ring, allocated off the audio thread. Level 0 alone until Task 12.
class RingStorage {
 public:
  RingStorage(int64_t frames, uint32_t maxBlockSize);   // N + maxBlock + 3 guard slots of 2 floats, zeroed; throws std::invalid_argument past 2^40 frames
  int64_t frames() const noexcept;                        // N
  int64_t capacity() const noexcept;                      // C = N + maxBlockSize
  float *slots() noexcept; const float *slots() const noexcept;   // slot s's channel c at 2s + c
  std::size_t bytes() const noexcept;                     // what it holds, for the memory budget
};
// LiveSource.h additions (every setter real-time safe, applied from the next write()):
static constexpr int64_t kAdoptCopyFrames = 8192;
static constexpr uint32_t kMaxSplices = 32;
void prepare(double sampleRate, uint32_t maxBlockSize) noexcept;      // no storage yet: rate, ramp, block
void prepare(double sampleRate, double seconds, uint32_t maxBlockSize); // kept: allocates an owned RingStorage (tests, gg-bench, gg-render's sample mode)
/// Swaps in `next`, whose slots already hold the window's frames below `copiedTo` at their slots
/// (frame f at f mod next->capacity()); copies [copiedTo, head()) itself, at most kAdoptCopyFrames,
/// else returns false and changes nothing. Ring time continues. `previous` gets the storage replaced
/// (nullptr when it was owned). Marks older than the new window are dropped.
bool adoptStorage(RingStorage *next, int64_t copiedTo, RingStorage *&previous) noexcept;
/// A restore: `next` holds frames [0, frames) at their slots; ring time restarts with head = frames,
/// not frozen, the write gain 1; the marks replace the current ones (ascending, < frames).
void restoreStorage(RingStorage *next, int64_t frames, std::span<const int64_t> marks, RingStorage *&previous) noexcept;
void setLoop(bool on, int64_t lengthFrames) noexcept;   // W = on ? min(length, N) : N, from the next write
void selectSplice(uint32_t k) noexcept;                  // 0: none; k > count clamps to count
bool addSplice(int64_t ringTime) noexcept;               // false when full, duplicate, or outside [head − N, head]
void clearSplices() noexcept;
uint32_t spliceCount() const noexcept; std::span<const int64_t> splices() const noexcept;  // ascending
int64_t windowFrames() const noexcept;                   // W in effect for the last write() block (a splice's span, the loop or N)
int64_t anchorAt(int64_t t) const noexcept;              // the window's end at t: headAt(t), or the selected splice's end (≤ head)
double anchorRunAfter(int64_t t) const noexcept;         // headRunAfter(t), or 0 while a splice is selected
/// write() gains the overdub gains: per frame, or nullptr for 0 throughout (the M1 path, bit for bit).
void write(const float *const *in, uint32_t numInChannels, uint32_t offset, int64_t blockStart,
           uint32_t numFrames, const float *overdubGain = nullptr) noexcept;
// Engine.h additions:
LiveSource &live() noexcept;                               // the mutable ring, for the Processor's window, splice and storage calls between process() calls
void process(const float *const *in, uint32_t numInChannels, float *const *out, uint32_t numChannels,
             uint32_t numFrames, const float *overdubGain) noexcept;   // the existing process() is this with nullptr
```

  Inside `LiveSource`: `fade(pos, head)` and `read(pos, head, …)` interpret `head` as the block's
  head and use the block's window `[end − W, end − 1]` with `end = anchor` (the head, or the
  splice's end clamped to the head), captured at `write()`; the guards use the same bounds. The
  overdub term is `o[j] × slot(frame R − P)` with `P = loop on ? min(L, N) : N`, added to the
  sanitized input before the freeze gain, then stored through `sanitize` again (the clamp). Marks
  are a fixed `std::array<int64_t, kMaxSplices>`; the selected splice `k` spans
  `[marks[k−1], marks[k])`, the last to the head; a selection whose span left the window (its mark
  dropped) falls back to 0. `Engine::liveGrain` uses `anchorAt`, `windowFrames()` and
  `anchorRunAfter` where it used `headAt`, `frames()` and `headRunAfter`.
