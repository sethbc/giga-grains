**Goal:** Build M2 sub-project 7, the close: the consistency fixes and the director's answers, the
carry-over burn-down, a from-scratch build setup, the ring reader's race, the spelling sweep, the
listening gate, the idle benchmark run and the `v0.2.0` release commit.

**Architecture:** Docs first (renames, then INTENT and the other documents with the director's

head, then the benchmarks, the final review and the release commit.

**Tech Stack:** C++23, CMake presets, Catch2 (tags become CTest labels), `gg-render` goldens,
`gg-bench`, GitHub Actions (`ci.yml`), bash and PowerShell.

row's evidence and per-row plan, with file:line, is in
`docs/superpowers/specs/2026-11-02-m2-close-evidence/triage-T1.md` to `triage-T4.md` (rows by family:

`docs/m2-consistency-review.md` (R-1 to R-69, X-1, X-2, K-1 to K-8). **A task that names a row does
exactly what that row's section in its triage report plans, unless this plan says otherwise.**

## Global Constraints

- CLAUDE.md's non-negotiables: the audio thread allocates nothing, takes no lock, makes no syscall,
  stays RTSan-clean and handles 0- and 1-sample blocks; output bit-identical at any block size;
  randomness only from the counter RNG; positions 64-bit.
- Every DSP or engine change: unit tests, `scripts/update-goldens.sh build/dev` before and after
  with the moved hashes named in the commit, `ctest --preset dev -L determinism` and `-L rt`.
  **Every golden WAV hash is unchanged except the five row 365 moves** (`inst-spectral`,
  `fx-spectral-freeze`, `presets/fx-06-spectral-mist`, `presets/fx-20-melting-clock`,
  `presets/inst-21-smoke-cathedral`).
- Test case names and tags are ASCII only. New tests are parallel-safe (CLAUDE.md, "Tests run in
  parallel").
- `-Wall -Wextra -Werror`; never edit a submodule; `scripts/format.sh` before each commit of C++.
- US English in all new and touched text (program, behavior, color, center, -ize).
- Models: no Fable, ever; `model` named on every dispatch; implementers haiku (mechanical) or
  sonnet (integration) as each task says, opus where a task says so; reviewers sonnet at least,
  opus for DSP, concurrency and the whole-branch final review.
- One `check.sh` gate per machine: `while pgrep -f '^[^ ]*bash [^ ]*scripts/check[.]sh' >/dev/null;
  do sleep 30; done` first. AU work under `until mkdir /tmp/gg-au.lock 2>/dev/null; do sleep 30;
  done` … `rm -rf /tmp/gg-au.lock`. Published timings only after the program manager's GO.
- Git: task worktrees branch from `m2-close`'s head and merge back by merge commit; `origin/main`
  is merged in by merge commit; no rebase, no force-push. PR #31 is reopened (`gh pr reopen 31`) at
  the first code commit pushed; never a new PR.
- Each conflict answer K-1 to K-8 is its own dated §23 row (2026-11-02, "the director, by forced
  choice, option 1"); the close's own row is the next free number after them.

## Review Focus

1. **A refactor that claims "bit-identical" but moves a golden** (rows 303, 343, 344, 348, 366,
   the spelling sweep). Expected: every hash equal; Tasks 6, 7, 9 and 15 compare
   `build/dev/golden/wav-sha256.txt` before and after and fail on any difference.
2. **A Spectral layer over its ring with Loop on and splices selected, at block size 1 and 512**
   (row 381). Expected: the same bytes at both block sizes, and every analysis frame inside the
   window. Task 8 pins it.
3. **The reverb turning active again after it went idle mid-render** (row 302: Amount 0 → 1 → 0 →
   1). Expected: each onset fades in, no click; Task 6 pins a second onset.
4. **A README one-liner run on a machine with half the prerequisites already installed** (§6.3).
   Expected: the script skips what is present and installs the rest, idempotent on a second run;
   Task 13's `scripts` test runs it twice with stubbed package managers.
5. **The ring reader under a storage swap while the head laps a whole copy** (rows 353 and 403).
   Expected: the copy is retried, never accepted with a stale frame; Task 4 pins it through
   `ringReadHook`.
