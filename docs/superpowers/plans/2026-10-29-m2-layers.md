# M2 Layers and Structure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give both plugins four layers, each M1's whole grain chain, mixed by a morph pad, rendered
as one task per layer on the host's thread pool, modulated by a 48-slot matrix whose first twelve
slots are the M1 macros, with pitch and size spread, a Source-kind parameter, the wave-2 parameter
structure and C++23, while every M1 golden keeps its WAV SHA-256.

**Architecture:**
- **`gg::Engine` stays one layer's engine** (its RNG `layer` key becomes configurable; it gains an
  enable gate, a click-free source-kind switch, the spreads and a one-level mip accessor). The
  `Processor` owns four `Layer`s, each an `Engine` plus M1's per-layer chain state (diffuser,
  Level, Feedback history, ring input, peaks, sample exchange, grain-event buffer), and sums their
  weighted wet signals in order A to D before the reverb and the mix.
- **Rendering is one task per on layer per 256-sample piece**, through a `TaskRunner` in `engine/`
  (serial, or the host's CLAP thread pool from the plugin). Grain events are buffered per layer
  and drained in layer order after the join, so the log never depends on threads.
- **Parameters are a flat slot space of 218** generated from one table of 48 layer parameters and
  the globals; IDs stay `(scope << 16) | index` with scopes 2 to 4 mirroring scope 1's indices.
- **The mod matrix** (`gg/core/ModMatrix.h`) replaces `macroOffsets`: 48 routes in the patch
  (`PTCH` version 2), six curves, every §14 source as a deterministic per-grid-cell state machine
  (`gg/core/ModSources.h`), evaluated into one `clamp(base + mod + Σ)` per parameter.
- **C++23 first**, with a revert path.

**Tech Stack:** C++23 (C++20 if Task 1 reverts), CMake 3.22/Ninja, Catch2, clap-helpers,
sst-basic-blocks `ParamMetaData`, sst-plugininfra PatchBase, nlohmann/json (gg-render), `gg-bench`.

**Spec:** `docs/superpowers/specs/2026-10-29-m2-layers-design.md` (approved by the program
manager 2026-10-29; the director's D1–D5 recorded). Read it before your task; its sections are
cited as "spec §n". The program design (`docs/superpowers/specs/2026-10-29-m2-program-design.md`
§6.1, §7) is the charter behind it.

## Global Constraints

**Non-negotiables** (CLAUDE.md; spec §4, §7):
- **Audio thread and pool threads:** no allocation, locks, I/O, syscalls, host calls or unbounded
  loops; RTSan-clean; 0- and 1-sample blocks; `params.flush` trivial. Everything a task needs is
  allocated in the `Processor`'s constructor.
- **Determinism:** output bit-identical at any host block size and `maxBlockSize`, and with no
  thread pool or a pool of 1, 2 or 8 workers; every value that can reach a grain or the audio is
  plain IEEE arithmetic, `exp2Det`, `logDet` or `std::sqrt`, never libm (LFO sine, envelope,
  follower coefficients, morph weights included). The RNG is `gg::rng` keyed by (seed, layer,
  stream, field, index); `rng::Field` is append-only: `PitchSpread = 5`, `SizeSpread = 6`,
  `ModRandom1 = 7`, `ModRandom2 = 8`. Layers are summed in order A, B, C, D.
- **The M1 sound is unchanged:** with layers B–D off, Morph X/Y 0.5, Pitch Spread 0, Size Spread 0
  and the factory routes alone, every one of the 22 M1 goldens keeps its WAV SHA-256
  (`scripts/update-goldens.sh` before and after every DSP task; the hash list in the commit),
  the sign of zero included. The `.events.jsonl` files are regenerated once (Task 10, the `layer`
  field); the `.metrics.json` files and WAVs must not move.
- **Stability contracts:** IDs append-only; no new scope; no index in `0x40`–`0x7F` of any scope
  (reserved for wave 2); the patch version bumps once, to 2 (Task 9); no new state chunk.
- **Ownership** (program design §6.1): shared files (`Processor.h`/`.cpp`, `ParamIds.h`,
  `tests/CMakeLists.txt`, INTENT, `SessionState.h`) only by addition; `ui/` changes only where
  a struct it reads gains a field; no edit under `libs/`.
- **Carry-over policy:** rows 118 and 119 of `docs/m2-carry-over.md` close here (Task 2 and
  Task 16); no net growth (13 open rows at the start; 11 at the end).
- **Formatting and commits:** `scripts/format.sh` before every commit; test case names ASCII
  only; commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` (or the
  session's attribution line). Run `scripts/check.sh` before reporting a task done and paste its
  summary.

| ID | `ParamSlot` | Name | Domain | Default | Flags |
|---|---|---|---|---|---|

A·M = `CLAP_PARAM_IS_AUTOMATABLE | CLAP_PARAM_IS_MODULATABLE`; S = `CLAP_PARAM_IS_STEPPED`.
`kParamCount` = 218: the 28 M1 slots (their enum names and order kept; layer A's), then layer A's
37 new slots in table order, then `B_Position` … `B_Step16` (48), `C_…`, `D_…`, then the nine
globals. **Next free index: `0x31` in every layer scope, `0x22` in scope 0.** Reserved in every
scope: `0x40`–`0x4F` (sub-project 2), `0x50`–`0x5F` (3), `0x60`–`0x7F` (4). Macro 7 is "Macro
Feedback", 0 by default, in both products; the instrument's hidden set becomes Mix and Dry to
Reverb (Feedback is shown).

**The factory routes** (spec §6.8), slots 1–12, each targeting every layer except Mix:
Macro1→Size +3 Bipolar; Macro1→Density −1.5 Bipolar; Macro2→Density +4 Bipolar;
Macro2→Distribution +0.25 BipolarPositive; Macro3→Pitch +24 Bipolar; Macro4→Spray +0.5 Bipolar;
Macro4→Stereo +0.3 BipolarPositive; Macro5→Texture +1 RampThreeQuarters; Macro5→Diffusion +1
TopQuarter; Macro6→Freeze +1 Unipolar; Macro7→Feedback +0.9 UnipolarSquared; Macro8→ FX: Mix
(global) +0.5 Bipolar, instrument: Level (every layer) +12 Bipolar. The curves are the exact float
expressions of today's `macroOffsets` (`core/src/ParamMap.cpp:81-126`): `2.0f * v - 1.0f`,
`std::max(b, 0.0f)`, `v * v`, `std::min(v / 0.75f, 1.0f)`, `smoothstep(0.75f, 1.0f, v)`, and a
contribution is `depth * curve(v)` added in slot order into an offset array that starts at +0.0f.

**The chain** (spec §6.3) per layer L, one task per 256-sample piece:
`ring_L[t] = sanitize(in[t]) + fb_L(t)·limited_L[t − 256]` (Live kind); `w_L = Σ grains_L`;
`w'_L = δ_L > 0 ? w_L + δ_L·(diffuse_L(w_L) − w_L) : w_L`; `limited_L = softLimit(w'_L · g_L)`;
`wet_L = limited_L · weight_L(t)`. Then `wet = wet_A ⊕ wet_B ⊕ wet_C ⊕ wet_D` (the first rendering
layer assigns, later ones add, off layers skipped), and M1's reverb and mix on `wet`.
`weight_L(t) = (r_L·b_L / Σ_K r_K·b_K) × min(1, Σ_K r_K)` over the rendering layers (D1; the
factor amended 2026-10-30 in Task 10's fix round, ruling LS-T10a, so the last layer switched off
fades over its ramp), with `x`, `y` the ramped Morph X/Y clamped to [0.001, 0.999],
`b_A = (1−x)(1−y)`, `b_B = x(1−y)`, `b_C = (1−x)y`, `b_D = xy`, `r_L` the layer's on/off
ramp, and `s > 0 ? (r_L·b_L / s) × min(1, Σ_K r_K) : 0`.

## Review Focus

The spec implies these inputs but no task's tests exercised them until this list was written;
each has a test pinned to the owning task:
1. **A layer switched off and on again within its 10 ms ramp:** the ramp retargets from its
   current value, the engine is never disabled, no forced onset fires twice, and no click. Pinned
   in Task 10 ("a layer toggled within its ramp keeps its grains").
2. **Every layer off:** the sum has no first layer, so the output is exactly +0 (not stale
   buffer contents), the reverb still runs on silence, and turning one on again speaks. Pinned in
   Task 10 ("all layers off renders silence").
3. **A route driving Source across its steps every cell** (a 20 Hz square LFO on A Source): no
   allocation, finite output, every grain finishes on the source it started on. Pinned in Task 12
   ("source kind modulated per cell does not allocate or click").
4. **A host pool that declines some requests** (`request_exec` returns false every other call):
   the output is bit-identical to the always-accepting and the serial renders. Pinned in Task 11
   ("a declining pool renders the same bytes") and Task 14 (the fake host).
5. **A version-2 state with a malformed `<mod>`** (a slot out of range, an unknown source or
   target name, a non-numeric depth): the state loads, the bad route is left empty, every other
   route and value is kept. Pinned in Task 9 ("a malformed route loads as an empty slot").
