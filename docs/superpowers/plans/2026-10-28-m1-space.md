# M1 Space Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give both plugins a per-layer diffuser and a global reverb (Surge's Reverb 2 with a small
patch), with eight new parameters, all off by default, deterministic and real-time safe.

**Architecture:**
- **The diffuser** (`gg::core::Diffuser`) is a small in-house allpass unit that runs per sample on
  layer A's grain sum.
- **The reverb** (`gg::core::SpaceReverb`) wraps a patched copy of sst-effects' `Reverb2`:
  - It feeds the reverb in 32-sample chunks aligned to the absolute control grid, so its return
    arrives a constant 32 samples late at every block size.
  - It latches the parameters per chunk and maps ∞ Decay to the patch.
- **The `Processor`** wires both into its wet chain (spec §6.1). The plugin adds the "Space"
  remote-controls page and CLAP's `tail` extension.

**Tech Stack:** C++20, CMake/Ninja, Catch2, sst-effects and sst-filters (GPL-3.0-or-later, new
submodules), sst-basic-blocks `ParamMetaData`, clap-helpers, `gg-render`, `gg-bench`.

**Spec:** `docs/superpowers/specs/2026-10-28-m1-space-design.md` (approved 2026-10-28, decisions
S1–S8). Read it before your task; its section numbers are cited below as "spec §n".

## Global Constraints

**Non-negotiables** (CLAUDE.md):
- **Audio thread:** no allocation, locks, I/O or syscalls; RTSan-clean; it must handle 0- and
  1-sample blocks.
- **Determinism:** output bit-identical at any host block size; no CPU-adaptive behaviour;
  `-ffp-contract=off` on every first-party and sst target; no `std::` random distributions.
- **The default sound:** with all eight new parameters at their defaults, `Processor` output is
  bit-identical to `main` at `5eefffc`, **including the sign of zero**. Every existing golden's WAV
  SHA-256 is unchanged.

**The parameters** (spec §6.5; slot order = parameter-list order = AUv2 order, appended after
Freeze):

| Slot | ID | Name | Domain (CLAP value) | Default |
|---|---|---|---|---|
| `Diffusion` | `0x01000B` | Diffusion | 0–1 (%) | 0 |
| `ReverbAmount` | `0x000003` | Reverb Amount | 0–1 (%) | 0 |
| `ReverbDecay` | `0x000004` | Reverb Decay | log2 s, −2 to `kDecayMax = 6.068255709804611` | 1.0 (2 s) |
| `ReverbSize` | `0x000005` | Reverb Size | 0–1 (%) | 0.5 |
| `ReverbDamping` | `0x000006` | Reverb Damping | 0–1 (%) | 0.3 |
| `ReverbPredelay` | `0x000007` | Reverb Pre-delay | 0–0.5 s (linear, shown in ms) | 0 |
| `ReverbModulation` | `0x000008` | Reverb Modulation | 0–1 (%) | 0.25 |
| `DryToReverb` | `0x000009` | Dry to Reverb | 0–1 (%) | 0 |

- **Decay's ∞ region:** values ≥ `kDecayInfinite = 5.906890595608519` (log2 60) are ∞. That is
  the top 2% of the travel; below it, 0.25 s to 60 s. The display shows "∞" there.
- **Flags:** every one is `AUTOMATABLE | MODULATABLE`.
- **The instrument** marks `DryToReverb` `HIDDEN` (as it does Mix), and the parameter has no
  effect there.

**The signal flow** (spec §6.1). Per sample, with `w` the engine's output, `d` the sanitized dry
input, `m` Mix, `g` Level, `δ` Diffusion, `a` Amount and `s` Dry to Reverb, each of the last
three ramped like Mix:
```
w' = δ > 0 ? w + δ·(diffuse(w) − w) : w          (the diffuser runs every sample regardless)
wet = softLimit(w' · g)
FX:   rIn = m·wet + s·d    out = d·(1 − m) + wet·m [+ softLimit(a·r)]
Inst: rIn = wet            out = wet               [+ softLimit(a·r)]
```
- **When the bracket applies:** the bracketed term is added only while the reverb is **active**
  (Task 5's idle rule). While it is idle, `out` is computed exactly as today.
- **The return `r`** is the reverb's output 32 samples after the input chunk that produced it.
- **One output channel:** channel 0 gets `r`'s left channel.

**Reverb 2's settings** (spec §6.3, voiced later at the listening check). Surge's parameter
values, set by `SpaceReverb`:
- **Fixed:** `rev2_diffusion` 1.0, `rev2_buildup` 1.0, `rev2_lf_damping` 0.2, `rev2_mix` 1.0, and
  width at its neutral (full stereo) value.
- **Mapped:**
  - `rev2_room_size` = 2·Size − 1;
  - `rev2_hf_damping` = Damping;
  - `rev2_modulation` = Modulation;
  - `rev2_decay_time` = Decay (log2 s), when finite.

**The patch** (S7, S8). It lives in a copy of `Reverb2.h` with every change marked
`// GG PATCH`. The file keeps its GPL-3.0-or-later header and adds a note saying it was modified
for Giga Grains.
- **∞ mode** (`setInfinite(true)`) sets four things:
  - the decay multiplier is exactly 1.0f;
  - the LF dampers are bypassed;
  - the HF coefficient's lower clamp is 0, not 0.01, so Damping 0 is lossless (`process_lowpass`
    with c0 = 0 is the identity);
  - `loopClip` runs on each block's `x` after the dampers.
- **`loopClip(x)`:** `x` when |x| ≤ 1, else `sign(x)·(2 − 1/|x|)`. It is bounded below 2, has
  slope 1 at the knee, and uses no libm.
- **Smoothed pre-delay** (`setPredelaySamples(float target)`; once it has been called, the
  original `rev2_predelay` path is unused): a fractional, linearly interpolated read whose delay
  moves linearly from its current value to each new target over `kPredelayGlideSeconds = 0.1`.
  The delay is ≥ 0, and 0 means the input passes straight through.
- **With neither change used,** the patched class renders bit-identically to upstream `Reverb2`.

**The pins:**
- `libs/sst/sst-effects` at `987b39d` and `libs/sst/sst-filters` at `87a171b`. These are
  shortcircuit-xt's pins, which pair with our sst-basic-blocks `9cee763`.
- Only AGPLv3-compatible dependencies.

**Tests:**
- Test case names are ASCII only.
- New DSP tests carry the Catch2 tag `[space]`, so `ctest --preset dev -L space` runs them.
- The hour-long renders also carry `[slow]`.

## Review Focus

1. **Host rates other than 48 kHz** (44.1, 96, 192 kHz).
   - The diffuser's lengths, the pre-delay buffer and Reverb 2's lines must all fit, and the
     renders must stay finite, with the onset scaling with the rate.
   - Pinned in Task 5 ("SpaceReverb at 44.1, 96 and 192 kHz") and Task 3.
2. **`maxBlockSize` below 32, and calls of 0 and 1 frames.**
   - A partial chunk is carried across many calls, and the output must be identical to one
     large call.
   - Pinned in Task 6 ("space output is block-size invariant", including `maxBlockSize` 1 and 7).
3. **A mono output, and a mono, missing or non-finite FX input with Dry to Reverb up.**
   - Expect finite output, channel 0 = the left return, and NaN input counted as 0.
   - Pinned in Task 6 ("space handles mono and missing channels").
4. **`reset()`, and deactivate/activate at a new rate, in the middle of a ringing or ∞ tail.**
   - After a reset, the output must equal a fresh instance's bit for bit.
   - Pinned in Task 5 ("SpaceReverb after clear matches a fresh instance") and Task 7
     ("reactivate at a new rate").
5. **Everything extreme at once.**
   - Decay flipping in and out of ∞ every 0.5 s, with Damping 0, Size 100%, Modulation 100% and
     Dry to Reverb 100%, on full-scale noise.
   - Expect finite output, |out| ≤ 2 + |dry|, and no allocation.
   - Pinned in Task 6 ("space extreme settings stay bounded").

### Task 5: SpaceReverb, grid-aligned

**Files:**
- Create: `core/include/gg/core/SpaceReverb.h`, `core/src/SpaceReverb.cpp`
- Test: `tests/core/space_reverb_tests.cpp`

**Interfaces:**
- **Consumes:** `Rev2Patched` (Task 2), and `SpaceParams` and `kDecayInfinite` (Task 4).
- **Produces:**

  ```cpp
  namespace gg::core {
  class SpaceReverb {
   public:
    static constexpr uint32_t kChunk = 32;               // == Processor::kControlGrid
    explicit SpaceReverb(double sampleRate);             // allocates Rev2Patched on the heap
    void reset() noexcept;                                // clear(); empty chunk; idle
    // One sample at absolute time t (t increases by 1 per call, from 0 after construction/reset).
    // `params` are the values in effect at t; a chunk uses the values at its first sample.
    // active: whether this sample belongs to an active chunk (see the idle rule).
    // Writes the return for t (the reverb's output for t − 32), 0 while idle.

                       bool active, float &outL, float &outR) noexcept;
  };
  }
  ```

  "the Amount ramp is not at exactly 0 at this chunk's first sample".

  - At the first active chunk after an idle one it calls `clear()` first, so raising Amount
    starts from an empty room.
  - This depends only on the parameter history on the grid.
- **The pre-delay:** at each chunk start,
  `setPredelaySamples(max(0, predelaySeconds × sr − 32))`.
- **∞:** at each chunk start, `setInfinite(params.infinite)`. When finite, `rev2_decay_time` =
  `decayLog2`.
