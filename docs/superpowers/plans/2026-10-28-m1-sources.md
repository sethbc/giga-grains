# M1 Sources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Giga Grains plays a loaded sample from notes (a chord is one cloud whose grains pick
held notes), Giga Grains FX freezes and repitches from notes, and the session state carries a
media manifest in §18's chunked container, found again on reopen.

**Architecture:**
- **Engine** (`gg-engine`): an immutable `PreparedSource` adopted real-time-safely, with a
  per-grain source slot so old grains finish on the old buffer. The `CloudScheduler` gains held
  keys, a per-grain note pick (`rng::Field::Note`), a note gate and a forced onset on note-on.
- **Core** (`gg-core`, JUCE-free): `NoteEvent`s on the 32-sample grid in the `Processor`;
  per-product parameter metadata and mapping; the `GGST` state container with the `MEDI` codec;
  the per-machine settings codec; `SourceExchange`, the main↔audio hand-off of sources.
- **Media** (new `gg-media`, JUCE-free, file I/O): decoding (dr_libs), SHA-256 (in-house),
  rate conversion (r8brain-free-src, new pinned submodule), `loadSample`, `findSample`, and the
  settings file.
- **Plugin:** note events into the `Processor`, a `SampleLoader` background thread, the
  synchronous session restore (D8), and the container state. **UI:** a loader strip in the
  placeholder editor. **`gg-render`:** an instrument mode, `notes`, FX file input, and generated
  test media.

**Tech Stack:** C++20, CMake/Ninja, Catch2 v3, dr_libs (pinned), r8brain-free-src 7.x (new,
MIT), sst-plugininfra's tinyxml (private to `gg-core`), clap-helpers, JUCE 9.0.4 (editor only),
nlohmann_json and CLI11 (`gg-render`).

**Spec:** `docs/superpowers/specs/2026-10-28-m1-sources-design.md` (decisions D1–D8). Read it,
`INTENT.md` §14, §15, §18 and §19, `CLAUDE.md` and `docs/m1-carry-over.md` before any task.

## Global Constraints

Every task's requirements include these. `CLAUDE.md` "Non-negotiables" holds in full.

- **No existing golden changes.** No task alters an existing case's `*.events.jsonl` or its
  metrics. New cases are added only in Task 13. Before Task 13, `ctest -L golden` passes unchanged
  after every task.
- **The audio thread** (`Processor::process`, `Engine::process`, the plugin's `process` and
  `params.flush`) never allocates, frees, locks, waits or does I/O for a load, a note or a state
  change. New audio-path functions are `noexcept SST_CPPUTILS_NONBLOCKING`.
- **Determinism:** note-driven renders are bit-identical at block sizes 1, 32, 64, 511 and 4096
  and under random splits. Randomness comes only from `rng::hash` with its own `rng::Field`.
  New `Field` values are appended: `Note = 4`.
- **Note timing:** a note event at absolute sample a applies at `ceil(a / 32) × 32`, in that
  boundary's group. Only the held set after the group counts.
- **Pitch:** a grain's semitones = effective Pitch + (key − 60), clamped to [−48, 48]. With no
  key held, the grain's rate is the scheduler's existing `pitchRatio_`, bit for bit.
- **Instrument Position:** CLAP value 0–1, displayed 0–100%, default 0. FX Position unchanged.
  Spray 0–2 s in both. No new parameters, no new IDs.
- **Formats:** WAV, AIFF/AIFC, FLAC, MP3. Mono or stereo; more channels keep the first two.
  **Cap: 600 s** of file duration. **State read cap: 64 MiB** (`64u << 20` bytes).
- **Paths** are UTF-8 in the state and the settings; Windows opens files through dr_libs' `_w`
  functions.
- **Dependencies:** r8brain-free-src pinned to an exact upstream 7.x tag's SHA in `.gitmodules`
  and INTENT §15. No other new dependency. SHA-256 is in-house.
- **`-ffp-contract=off`** on everything first-party and on r8brain; never fast-math.
- **Pushing a branch or dispatching CI is outward-facing:** ask the director first (Task 15).
- **Each task ends with `scripts/check.sh` printing `PASS`** (default presets `dev,asan,rtsan`);
  paste its summary in the task report. Format with `scripts/format.sh`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Conditions the spec implies that no task's main tests would hit, most likely first. Each has a
test in the owning task.

1. **A note-off that never comes** (a host stops the transport mid-note, or the plugin is reset):
   `reset()` must clear the held set, and CC 123 its channel's notes (ruling R14), or the
   instrument drones forever. Task 7.
2. **A load or relink requested while another is still decoding:** the newer request wins, the
   older result is dropped, and nothing leaks. Task 11.
3. **A state saved while the sample is missing:** the saved `MEDI` entry survives unchanged.
   Task 11.
4. **A file whose extension lies** (an MP3 named `.wav`, a truncated file, a zero-length file):
   a clean error message, never a crash or a hang. Task 2.
5. **A sample loaded while notes play, at a rate different from the host's:** no click, the old
   grains finish on the old buffer, pitch stays right throughout. Task 4 (engine) and Task 11
   (plugin).

- Behavior, exactly:
  - **Pick:** while n > 0 keys are held, each grain draws

    the pending onset to its `blockStart`, and clears `hasLast_` and `rescalePending_`.
  - **Gate:** with the gate on and no keys held, `schedule()` emits nothing (as when off).
