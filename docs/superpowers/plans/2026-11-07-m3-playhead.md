# M3 Playhead Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each layer gets a playhead: Position is where reading starts, Scan Speed moves the read point from there (signed, × real time, cubic law), Scan Edge wraps, bounces or stops it at the source's window, every voice restarts its own at note-on, Scan Track scales a voice's speed with its note; at Scan Speed 0 nothing moves.

**Architecture:** A header-only `gg::Playhead` (closed-form offset `x(t) = x0 + r (t − τ0)`, rebased only when the rate or edge changes) lives in every `CloudScheduler`. The `Engine` syncs each stream's playhead at every block start with the source's geometry; Sample mode folds the point in `takeNext`, ring modes fold it in `liveGrain` with the window at the grain's onset, and the Spectral smear evaluates the layer playhead at each hop. The `Processor` maps the three parameters into `CloudParams` (Scan Speed per voice, with the track ratio).

**Tech Stack:** C++23, Catch2, CMake presets, `gg-render` goldens.

**Spec:** `docs/superpowers/specs/2026-11-07-m3-playhead-design.md` (H0 to H13, HB1 to HB12; parent `docs/superpowers/specs/2026-11-07-m3-program-design.md`). File references are at `e8e0775`.

## Review Focus

1. **A Sample layer at Position 1.0 (the file's end) with Wrap:** the fold must map it to the end the instant it starts (x = 0 gives Position, not 0), and the first moving grain lands just past 0. (Task 2's `scanFold leaves the window's ends`, Task 3's `a scan from the sample's end wraps to its start`.)
2. **Scan Speed automated at a sample inside a host block, rendered at block sizes 1, 7 and 333:** the rebase lands on the grid boundary, never on a block start, and the bytes are equal. (Task 4's `scan speed automation is block-size invariant`.)
3. **The last splice selected while the head records, with Wrap and Stop:** the window grows within a block; the fold uses each grain's own onset window and the playhead never rebases on it. (Task 3's `a growing splice window never rebases the playhead`.)
4. **A sample replaced while scanning (a capture into the layer, or a load):** the point keeps its fraction and continues at the new file's rate; no NaN when the new file has one frame. (Task 3's `a new sample keeps the playhead's fraction` and `a one-frame sample holds the playhead`.)
5. **Scan Speed back to 0 after moving, then a note:** the point holds where it stopped until the restart returns it to Position; Cloud's restart at the first key after none in both products. (Task 3's `scan zero holds the point`, Task 4's `the cloud playhead restarts at the first key after none`.)
